# Day 11 - Prompt Comparison

## Objective

Compare Java code generated by GitHub Copilot using
a vague prompt and a specific prompt.

## AI Tool

GitHub Copilot

## Vague Prompt

Generate a simple Java class named VagueStudent.

## Specific Prompt

Generate a Java 21 Student POJO containing:

- Five private fields
- Default and parameterized constructors
- Getters and setters
- Input validation
- Exception handling
- toString() method

## Comparison

| Feature | VagueStudent.java | Student.java |
|---------|-------------------|--------------|
| Class generated | Yes | Yes |
| Private fields | No | Yes |
| Constructors | Implicit default | Explicit default and parameterized |
| Getters | No | Yes |
| Setters | No | Yes |
| Encapsulation | No instance state | Private fields with public accessors |
| Input validation | No | Yes |
| Exception handling | No | IllegalArgumentException |
| toString() | No override | Overridden |
| Completeness | Empty class | Functional POJO |

## Observations

1. The vague prompt generated an empty Java class.
2. The specific prompt generated a complete Student POJO.
3. The specific implementation included validation.
4. The specific implementation followed encapsulation.
5. The detailed prompt produced code that more closely
   matched the intended requirements.

## Conclusion

Specific prompts produce more targeted code because
they clearly describe the expected requirements.

However, all AI-generated code must still be
reviewed and tested before use.
